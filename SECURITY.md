# Sicherheit / Security

Bitte melde Sicherheitslücken in ClusterDeck oder am Cluster DM3KS-9 **nicht als öffentliches Issue**, sondern per E-Mail an **info@dm3ks.de**. Beschreibe kurz, was betroffen ist und wie man es nachstellen kann. Du bekommst zeitnah eine Antwort; nach der Behebung nenne ich dich gern als Finder, wenn du möchtest.

Please do **not** report security issues in ClusterDeck or the DM3KS-9 cluster as a public issue. E-mail **info@dm3ks.de** with a short description and how to reproduce it. You'll get a prompt reply; once fixed, I'm happy to credit you if you like.
