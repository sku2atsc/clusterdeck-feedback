# ClusterDeck · DM3KS-9 – Feedback

Hier sammeln wir **Fehlermeldungen und Wünsche** für den DX-Cluster **DM3KS-9** und seine Weboberfläche **ClusterDeck**.
This is the place for **bug reports and feature requests** for the DX cluster **DM3KS-9** and its web interface **ClusterDeck**.

- 🌐 Web: <https://dxc.dm3ks.de>
- 🎯 Activity Hunting Tool (POTA, SOTA, IOTA …): <https://dxc.dm3ks.de/ota>
- ☀️ HF-WX: <https://dxc.dm3ks.de/sonne>
- 📟 Telnet für Logprogramme / for logging software: `dm3ks.de:7300`
- 📖 Anleitung / Guide: <https://dxc.dm3ks.de/hilfe>

> Der Quellcode liegt nicht in diesem Repository – es dient nur als Anlaufstelle für Rückmeldungen.
> The source code is not in this repository – it is only used for feedback.

## Mitmachen / How to contribute

1. **[Neues Issue anlegen / open a new issue](../../issues/new/choose)** und die passende Vorlage wählen:
   - 🐞 **Fehler melden / Bug report** – etwas funktioniert nicht
   - 💡 **Wunsch / Feature request** – Idee für eine neue Funktion
   - 📡 **Spots & Daten / Spot & data problem** – falsche oder fehlende Spots, Referenzen, Länder
2. Vorher kurz [die vorhandenen Issues](../../issues) durchsuchen – vielleicht gibt es das schon. Dann lieber mit 👍 abstimmen als doppelt melden.
   Please search [existing issues](../../issues) first – a 👍 on an existing one helps more than a duplicate.
3. Deutsch oder Englisch – beides ist willkommen. / German or English – both are welcome.

## Bitte nicht hier / Please not here

- **Passwörter, E-Mail-Adressen, Zugangsprobleme** – Issues sind öffentlich. Bitte per E-Mail an <info@dm3ks.de>.
  Passwords, e-mail addresses, account problems – issues are public. Please e-mail <info@dm3ks.de>.
- **Sicherheitslücken** – bitte vertraulich per E-Mail, siehe [SECURITY.md](SECURITY.md).
  Security issues – please report privately, see [SECURITY.md](SECURITY.md).
